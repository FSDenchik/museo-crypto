# Аналитика прохождений

При завершении игры браузер отправляет на `/api/attempts` идентификатор прохождения,
время начала и окончания и баллы по девяти вопросам. Имена, введённые пароли и
тексты ответов **не отправляются**. Сервер проверяет диапазоны баллов и время,
самостоятельно вычисляет суммарный балл и профиль, затем сохраняет запись в SQLite.
Повторная отправка одного идентификатора не создаёт дубль. Если сеть пропала,
клиент сохраняет до 20 неотправленных результатов и повторяет отправку при
следующем открытии сайта или восстановлении подключения.

Админ-панель `/admin.html` запрашивает `/api/admin/stats` после серверной
проверки пароля. Отображаются реальные агрегаты, графики и обезличенные
прохождения; выбор периода и CSV-экспорт работают по данным сервера.
Индикатор «Анонимных сессий» означает число завершённых прохождений, а не
уникальных людей.

## Запуск

```powershell
docker compose up -d --build
```

Сайт: `http://localhost:8080/`; админ-панель: `http://localhost:8080/admin.html`.
Пароль для локального запуска — `123`. Перед публикацией создайте `.env`
рядом с `docker-compose.yml`, задав **длинный уникальный пароль**:

```dotenv
ADMIN_PASSWORD=замените-на-длинный-случайный-пароль
```

Размещайте сервис только за HTTPS reverse proxy. В браузере пароль вводится
через диалог, а сервер выдаёт временный HttpOnly SameSite cookie. При перезапуске
контейнера потребуется войти снова. Публичный API приёма результатов открыт
для анонимных игроков: диапазоны данных проверяются, но без пользовательской
аутентификации невозможно гарантировать, что каждое прохождение сделано человеком.
Для высоконагруженного или публичного проекта добавьте ограничение запросов
на уровне reverse proxy и мониторинг.

SQLite находится в Docker volume `museodecrypto_museo-data` по пути
`/app/data/analytics.sqlite3` внутри контейнера. Не удаляйте volume при
обновлении. Для резервной копии используйте штатный SQLite backup API или
остановите контейнер перед копированием файла базы.

## Проверка

```powershell
python -m unittest test_server.py -v
```

Интеграционный тест в этом репозитории проверяет API, защиту доступа,
валидацию, идемпотентность записи и фильтр дат. Сохранение при реальном
завершении игры также проверено в браузере на временной базе.
